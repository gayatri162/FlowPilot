# FlowPilot — Prototype Submission

## Run the prototype
Open `index.html` in a modern browser. No installation, package manager, backend, or API key is required.

## Features
- Goal input and timeframe selection.
- Six-step rule-based starter workflow.
- Responsive interface.
- Download plan as a `.txt` file.
- Empty input validation.

## Honest limitations
This is a front-end prototype using JavaScript templates, not a live AI application. It has no login, database, backend, or user analytics. User need and usefulness have not yet been validated. Do not claim user testing or measured impact unless you have actually completed it.

## Suggested tests
1. Submit empty input and check that the form requests a goal.
2. Enter a short goal and generate a workflow.
3. Try each timeframe.
4. Download and open the `.txt` plan.
5. Check the layout on a narrow/mobile screen.
6. Ask someone unfamiliar with the project to use it and document their actual feedback.
